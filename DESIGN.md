# Design System Specification — AURA
**Theme:** Cyberpunk Deep Glassmorphism & High-Density Terminal

## 1. Visual Hierarchy & Color Palette
* **Deep Space Base:** Radial gradient `radial-gradient(circle at 50% 10%, #150d2a 0%, #070312 100%)`
* **Glass Container:** `background: rgba(18, 12, 38, 0.75)` with `backdrop-filter: blur(16px)`
* **Structural Borders:** Hairline borders `1px solid rgba(139, 92, 246, 0.25)`
* **Electric Cyan (`#38bdf8`):** Live telemetry, system health nominal, verified objectives.
* **Neon Purple (`#c084fc`):** Cognitive context, AI inference badges, primary brand accents.
* **Amber Warning (`#f59e0b`):** Streak recovery challenges, daily routine flags, freeze shield warnings.
* **Crimson Critical (`#f43f5e`):** Banned operator notice, expired sessions, authorization errors.

## 2. Interactive Components
* **Dynamic Morning Card:** Right-hand executive pod rendering real-time daily goals, pending reminders, and an interactive audio player.
* **Search / Command Matrix:** Global directive input featuring a file attachment button (`+`) for multi-modal ingestion.
* **Domain Quick-Toggles:** Modular action buttons that launch users directly into tailored workspaces.
